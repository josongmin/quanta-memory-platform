## Selection rule

Keep semantic regression oracles in the owning module. Use a subprocess integration test only when `SIGKILL` and a cold Redb reopen are the behavior under test. Do not repeat an existing selector under a new name, use sleeps to force a race, or expect process-resident data after the documented terminal finalize handoff.

## Contract-first residuals — do not greenwash with tests

- **I07 content identity:** Redb rejects different bytes on a same-ID `commit_spill` retry, but the generic `resolve_record(id)` returns existence/disposition, not an expected-content proof. Decide whether custom durable backings and on-disk corruption belong to this contract. If yes, carry expected digest/length through pending spill authority and reconciliation, then inject same-ID/different-content and prove the source remains fenced. If no, document the trusted-backing boundary and keep the checklist score limited. No actual source loss has been reproduced.
- **I04–I06 physical/resource budget:** record count, disk bytes, in-flight I/O and codec/decode scratch have no enforced common limit. Choose exact budget units and a backing/codec admission owner before negative tests; then inject disk-full, oversized decode, and scratch-denied restore and check source/durable authority plus peak ledger/allocator postimage. A test that merely checks a Redb file's platform-dependent byte size is not an oracle.
- **Current Redb-specific evidence:** `RedbSpillBacking::create` uses `Database::create` without a cache-size override; locked `redb 2.6.3` initializes its builder with a 1 GiB cache setting. `commit_spill` accepts arbitrary bytes, while `prepare_restore` and `recover_active_restore` clone the persisted payload into an uncharged `Vec`. An idempotent-write probe's extra clone was removed, but that does not close output, decode, physical-file, or concurrent-I/O bounds. Redb has no exposed hard file-size cap in its builder; a logical payload quota must not be described as a physical disk guarantee. The consuming host must supply a real volume/quota and ENOSPC qualification for that claim.
- **M06/M07/M09/M10 qualification:** the scaling verifier does enforce a default p99 ≤1s and optional baseline comparison; it does **not** establish per-outcome production SLOs. After a clean source freeze, run its full cardinality matrix, an opt-in phase-change semantic soak, extraction, and an exact QMP/host tuple if the host uses this feature. Keep local, host, hosted CI, deployment and activation separate. Existing L2 EIO receipts belong to an older source digest.
