## Selection rule

Keep semantic regression oracles in the owning module. Use a subprocess integration test only when `SIGKILL` and a cold Redb reopen are the behavior under test. Do not repeat an existing selector under a new name, use sleeps to force a race, or expect process-resident data after the documented terminal finalize handoff.

## Contract-first residuals — do not greenwash with tests

- **I07 content identity:** Redb rejects different bytes on a same-ID `commit_spill` retry, but the generic `resolve_record(id)` returns existence/disposition, not an expected-content proof. The current accounting-bearing durable SPI is sealed; no foreign backing is an in-scope release implementation. A future open SPI must negotiate versioned/opaque evidence and fail closed when verification is required but unavailable, without hard-wiring one digest algorithm. Redb corruption detection beyond its transactional metadata/disposition checks remains an explicit unqualified boundary. No actual source loss has been reproduced.
- **I04–I06 remaining physical/codec budget:** record/count/logical payload, backing-owned staging and Redb file length are now bounded; private caller encoder/decoder allocations and output produced before `commit_spill` admission are not. Define a bounded codec owner/API or host contract and inject scratch denial. The per-file cap does not reserve volume capacity or prove ENOSPC behavior. The consuming host must supply a real volume/quota and ENOSPC qualification. File-cap denial can make the current Redb handle refuse further I/O; close/reopen and, if restore needs headroom, raise the cap before retrying the persisted claim.
- **M06/M07/M09/M10 qualification:** the scaling verifier does enforce a default p99 ≤1s and optional baseline comparison; it does **not** establish per-outcome production SLOs. After a clean source freeze, run its full cardinality matrix, an opt-in phase-change semantic soak, extraction, and an exact QMP/host tuple if the host uses this feature. Keep local, host, hosted CI, deployment and activation separate. Existing L2 EIO receipts belong to an older source digest.
