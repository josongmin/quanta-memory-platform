## Change summary

- `ProcessMemoryBrokerBuilder::build()` and facade
  `MemoryPlatformBuilder::build()` now return enforced live products;
  `build_report_only()` is the authority-free configuration product. Both use
  the same resolver and override provenance.
- `attach_runtime()` now returns a broker-bound runtime view. Scratch reserve
  owns the QMP-020 pending authority, charges `ExecutionScratch/LiveScratch`
  across class/owner/context/resource-group axes, denies before allocation, and
  refunds on explicit release or Drop.
- `ScratchReservation` is non-Clone with private fields and private release
  authority. Failed explicit release keeps retry authority; final Drop performs
  exact pending cleanup even after broker-lock poison.
- Raw/basic broker, runtime, scratch and ledger construction paths were removed
  or made crate-private. Public bumpalo scratch was removed. The disconnected pin
  registry is explicitly `UnbudgetedPinRegistry` behind non-default
  `unbudgeted_pin`.
- Facade disables core dependency defaults; feature rails now run clippy
  `-D warnings` on default/bare/leaf/full/all axes and inspect the resolved graph
  for facade-to-core live feature leakage.
