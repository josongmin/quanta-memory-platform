## Implemented contract

- Independent model state covers class, owner, five context axes, charge kind,
  two resource groups, rebuild state and live ticket authority.
- 128 generated traces execute the same operation sequence against an honest
  fake and the real grouped broker. Denials preserve the full observation,
  every successful ticket has one terminal release and final drain is exact
  zero with no live ticket.
- The fake owns separate context and group maps; it does not copy those values
  from owner totals. Production observation exposes live tickets and scheduler
  usage from one broker lock.
- Negative targets are checked against exact violated-family sets. A reentrant
  event sink re-observes the broker without deadlock or semantic drift.

## RED evidence

context truth from owner totals, derived group truth instead of storing it, and
could not observe a zero-byte live ticket. The new exact axes and generated
runner reject those preimages; existing black-hole, swallowing, wrong-axis,
stale-ticket, observation-error and double-owner targets remain RED with exact
family attribution.
